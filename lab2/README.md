# Лабораторна робота №2 — Побудова чудових кривих

Варіант 4: **трисектриса Лоншама**.

- Полярне рівняння: `r = a / cos 3φ`, −π/2 < φ < π/2, розриви при φ = ±π/6, ±π/2
- Декартове рівняння: `x³ − 3xy² = a(x² + y²)`
- Асимптоти: `x = −a/3`, `y = ±x/√3 ∓ 2a/(3√3)` — утворюють рівносторонній трикутник площею `a²/√3`

## Запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
npm start      # http://localhost:3000
npm test       # перевірка математики (node:test)
```

## Що вміє програма

1. Будує криву (три гілки окремими ламаними, без хибних ліній через розриви), осі та сітку з підписами.
2. Дефолтні параметри: `a = 3`, `φ = 12°`, перетворень немає. Усе змінюється під час роботи.
3. Анімація: параметр `a` «пульсує» в проміжку 1…6; окремо можна запустити рух точки P вздовж кривої.
4. Дотична й нормаль у довільній точці P (аналітична похідна, формули (11)–(12) методички) + їх рівняння.
5. Три асимптоти (вмикаються/вимикаються) і асимптотичний трикутник.
6. Розрахунки: довжина дуги від вершини гілки до P (Сімпсон), відсутність точок перегину
   (аналітично й чисельно), площа асимптотичного трикутника, площа між гілкою та асимптотами (a²/(3√3)), площі сектора й сегмента кривої,
   радіус кривини (аналітична формула та перевірка через параметричну).
7. Евклідові перетворення: зсув на (Δx, Δy) і обертання навколо довільної точки (px, py)
   матрицями (22), (23) в однорідних координатах. Перетворюються всі об'єкти: крива, асимптоти, дотична, нормаль.

Колесо миші — масштаб, перетягування — зсув виду.

## Структура

```
server.js                    статичний сервер (node:http)
public/
  index.html, styles.css     інтерфейс
  js/main.js                 зв'язок стану, UI, анімації і малювання
  js/math/trisectrix.js      модель кривої: точки, похідні, асимптоти, характеристики
  js/math/matrix.js          матриці зсуву/обертання, композиція
  js/math/numeric.js         Сімпсон, формула Гаусса, довжина ламаної
  js/render/renderer.js      малювання сцени на canvas
  js/core/state.js           дефолтні параметри
  js/core/animation.js       анімація параметрів
  js/core/analysis.js        розрахунки для панелі результатів
test/trisectrix.test.js      тести математики
```
