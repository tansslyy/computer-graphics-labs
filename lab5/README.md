# Лабораторна робота №5 — Проекціювання

Варіант 4: метод 8 — ізометрія на площину y = p. Грановане тіло — огранений діамант (майданчик, коронка з трикутних граней, рундист, павільйон).

## Запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
npm start      # http://localhost:3000
npm test
```

## Можливості

1. **Параметри тіла.** Кількість граней, радіус, ширина майданчика, висота коронки, глибина павільйону, масштаб.
2. **Евклідові перетворення.** Зсув по X, Y, Z та обертання навколо власних осей тіла через його центр (рожева точка). Є кнопка з прикладом із завдання: зсув на 100 по X і Y та поворот на 90° по Y.
3. **Анімація.** Параметр змінюється між мінімумом і максимумом, а кожен кадр тіло додатково зсувається та обертається на задані кроки.
4. **Параметри проекції.** Кути ψ (навколо Z) і φ (навколо X) та положення площини p. Пресети: ізометрія, вид спереду, вид зверху, вид збоку. Тип проекції (ізометрія / диметрія / триметрія) визначається за коефіцієнтами спотворення.
5. **Вид збоку.** Показує площину y = p і проекціювальні промені, тож видно, як змінюється p.
6. **Режими відображення.** Грані з заливкою, невидимі ребра пунктиром, каркас.

Матриця проекції: `M = Rz(ψ) · Rx(φ) · Mорт(y = p)`. Для ізометрії `sin ψ = 1/√2`, `sin φ = 1/√3`.

## Структура

```
public/js/math/mat4.js         матриці 4×4: зсув, масштаб, обертання, обертання навколо центру
public/js/math/projection.js   матриця ізометрії на y = p, коефіцієнти спотворення
public/js/model/diamond.js     вершини, грані та ребра діаманта
public/js/render/scene.js      конвеєр: модель → W → проекція
public/js/render/renderer.js   малювання сцени та виду збоку
public/js/main.js              інтерфейс, анімація
test/projection.test.js
```
