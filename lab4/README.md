# Лабораторна робота №4 — Побудова гладких криволінійних контурів

Варіант 4: контур №27 (скакалка і дві зірочки), криві другого порядку в інженерному вигляді. Проєкт ЛР №3, доповнений гладкістю 1-го порядку.

Типи точок:

- **вузлова точка** (синя) — стик, у якому забезпечується гладкість;
- **точка зламу** (червона) — стик без гладкості;
- **реперна точка** (помаранчева) — точка B характеристичного багатокутника.

## Запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
npm start      # http://localhost:3000
npm test
```

## Що додано

1. При переміщенні реперної точки у вузловій точці протилежна реперна точка сусіднього сегмента підлаштовується так, що дотична лишається неперервною.
2. У точці зламу протилежна реперна точка не рухається.
3. Подвійний клік по стику (або кнопка «Вузлова ⇄ злам») перемикає його тип; при перетворенні на вузлову дотичні вирівнюються.
4. «Рівні дотичні (C¹)» — додатково вирівнюються довжини похідних з обох боків стику.
5. Галочка «Забезпечувати» вмикає/вимикає гладкість для всього контуру.

Умова гладкості: `r1'(1) = α1·T`, `r2'(0) = α2·T`, де для раціональної кривої 2-го порядку `r'(0) = 2·wB/wA·(B − A)`, `r'(1) = 2·wB/wC·(C − B)`. Реалізація — `public/js/math/smooth.js`.
