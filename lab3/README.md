# Лабораторна робота №3 — Моделювання криволінійних контурів

Варіант 4: метод 3 (криві другого порядку в інженерному вигляді), контур №27 — скакалка і дві зірочки.

Контур складається з 7 елементів і 37 дуг:

- скакалка — 11 дуг, гладкі стики;
- ручки — по 4 дуги;
- наконечники — еліпси з 4 дуг, `wB = cos 45°`;
- зірочки — по 5 дуг, кожен промінь — дуга гіперболи (`wB = 1.4`).

## Запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
npm start      # http://localhost:3000
npm test
```

## Можливості

1. Побудова контуру за формулою `r(u) = (rA·wA(1−u)² + 2rB·wB·u(1−u) + rC·wC·u²) / (wA(1−u)² + 2wB·u(1−u) + wC·u²)`.
2. Характеристичний багатокутник і реперні точки, які можна приховати.
3. Перетягування точок мишею, опція збереження гладкості стиків.
4. Зміна ваг wA, wB, wC вибраної дуги, тип дуги за дискримінантом f.
5. Морфінг у розгорнуту скакалку (зірки стають колами), повзунок t або анімація.
6. Перенесення й обертання навколо довільної точки матрицями в однорідних координатах.
7. Збереження та відкриття контуру у JSON.
